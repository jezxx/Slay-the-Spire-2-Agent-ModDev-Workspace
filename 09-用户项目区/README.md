# 用户项目区

这里保存用户自己的正式模组和本地项目资料。每个模组使用独立目录和独立 Git，即使属于同一个用户，也不要把两个模组的源码、资源、数值、任务记录、决定或提交历史混在一起。

每个模组目录至少应有自己的 `PROJECT.md`，其中登记项目定位、当前状态、常见指代、证据入口、专属约定和工具/数据位置。任务记录、决策记录和测试记录按实际需要建立，不要求每个小任务都写。Agent 开始任务前先确认当前目标模组和该项目 Git 的已有修改。

这里的内容不会自动进入公共核心，也不会自动进入其他模组。项目专属的机制实现、数值、美术选择、用户偏好和临时脚本都留在项目目录。Agent 发现可跨项目复用的内容时，先写入根目录待整理经验/，经过验证和脱敏后再整理到公共目录。

公共经验如果还值得其他工作区同步，再按门槛摘要写入根目录经验传递文档.md；不要把整个项目文件夹或大段私人源码放进去。

新项目优先用 `04-工具\工作流\new-mod.ps1` 创建，它会在 Git 可用时初始化项目仓库。现有项目没有 Git 时，在第一次正式修改前建立仓库和基线提交；不要把 `09-用户项目区` 取消忽略后塞进公共仓库。
