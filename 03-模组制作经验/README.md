# 模组制作经验

这里放已经确认具有普遍价值的经验，不放某个私人模组的当前状态。目录已经从入门流程扩展到故障诊断、机制时序、本地化、资源缓存、自检、迁移、事件与奖励、队列状态、角色资源契约、媒体验收和工具可靠性。

经验文档应尽量采用“现象、根因、修法、证据、适用范围、限制”的结构。只有编译成功但没有行为证据的猜测，不能写成正式结论。

这是可演进的公共经验区。Agent 可以在本地验证后修正文档、补充失败方案或增加新的通用专题，但必须保留版本、证据和限制条件。项目专属经验先留在项目档案或待整理经验/。

当一项改动不仅应进入当前工作区，还值得其他不相关工作区同步时，才把它摘要写入根目录经验传递文档.md。经验传递文档是交换队列，不是本目录的替代品；交换完成后，稳定内容应回到本目录，已处理条目再清空。
