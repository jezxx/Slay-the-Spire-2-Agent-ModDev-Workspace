# 对象与资源定位

## 先确认游戏对象

用户说“状态”“图标”“遗物图”时，Agent 先确认它属于哪个对象和显示位置。常见对象包括卡牌、遗物、药水、Power、附魔、角色、事件、地图节点和 UI 控件。

## 资源的显示层级

同一个对象可能有多份资源：

- 原始贴图。
- 游戏运行时的小图标。
- 百科列表缩略图。
- 百科详情大图。
- 卡牌或 UI 场景中的贴图。
- PCK 中导出的实际资源。

用户描述不清时，应先用画面位置和操作询问，而不是按文件名猜测。

## 资源定位顺序

1. 搜索用户点名的界面和对象。
2. 搜索代码中声明的资源路径。
3. 搜索资源导入文件和场景引用。
4. 检查 PCK 是否实际包含资源。
5. 运行游戏验证最终显示。
