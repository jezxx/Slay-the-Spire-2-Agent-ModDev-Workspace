# 版本适配

游戏更新后，最可靠的方式是保留旧版本资料，重新导出当前版本，再对比类型、成员、调用顺序、资源路径和本地化行为。

可以根据旧版本经验快速提出适配方案，但“能够编译”不等于“语义兼容”。至少要验证：

- 注册和加载。
- 代码路径实际执行。
- UI 和资源能读取。
- 关键行为与旧版本的预期一致。
- 旧项目是否需要兼容分支。

每次适配都应记录旧版本、新版本、变化点、修复方式和验证证据。
