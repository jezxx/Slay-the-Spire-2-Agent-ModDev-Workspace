# 示例项目

这里放脱敏、最小、可以独立理解并说明一种制作流程的示例。当前最小可运行示例位于 05-模板/原生模组模板/，包含一张原生 C# 卡牌。

## 内容方向入口

- 卡牌：先复制原生模板中的 ExampleCard.cs，再按社区教程 BaseLib/01 - 添加卡牌/ 和当前 API 资料核对。
- 遗物：参考 BaseLib/03 - 添加新遗物/，并以 RelicModel、RelicCmd 和当前版本的遗物注册/池规则为准。
- 药水：参考 BaseLib/06 - 添加新药水/，以 PotionModel、PotionUsage、TargetType 和 PCK 图片路径为准。
- Power：参考 BaseLib/05 - 添加新能力/，以当前 PowerModel、PowerCmd 和图标路径为准。
- 事件：参考 BaseLib/12 - 添加新事件/，复杂事件先读当前 EventModel、EventOption 和奖励 API。
- 人物、怪物、UI、动画和特效：先读对应教程，再查 02-游戏反编译资料/；这些方向通常需要额外的场景、美术、动画或第三方框架验证。

## 示例进入标准

新增示例必须：

- 不包含私人模组源码、资源、路径、账号或未确认授权内容。
- 说明目标、文件、适用版本、依赖、运行结果和已知限制。
- 能帮助不相关的模组理解一个通用问题。
- 至少完成最小编译、资源导出或运行验证之一，并写明尚未验证的部分。
