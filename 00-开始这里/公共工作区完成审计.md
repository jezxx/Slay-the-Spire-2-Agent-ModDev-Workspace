# 公共工作区完成审计

更新时间：2026-10-04

本文件记录当前本地公共包已经实际检查过的内容和仍然需要外部条件的内容。它不是教程，也不是用户必须逐项阅读的文件；Agent 在判断“能不能直接开始”时可以把它当作事实边界。

## 已完成的本地检查

- 21 个 PowerShell 脚本均通过语法解析。
- 环境预检可以识别 .NET 9 SDK、游戏目录、游戏程序集、Python/Pillow/numpy 和 Godot 的状态；缺少可选工具时会明确标记任务边界。
- 公开模组创建脚本可以生成工程、清单、项目档案和本地化入口。
- 用本机 .NET 9.0.318、实际游戏数据目录和临时生成的公开模组工程完成过还原、编译和 DLL 新鲜度检查。
- 查询工具全量构建通过，包含 API、枚举、ID、IL、成员签名、PCK、PNG 等工具。
- API 导出流程已用当前游戏程序集完成一次版本化索引烟测；输出写入指定目录，不覆盖旧版本目录。
- PCK 打包、列举和验证工具已用最小资源目录互相验证；读取器也已读取原版模组 PCK 的目录和数据偏移。
- 工作流脚本支持显式游戏目录、.NET 路径和临时目录，不依赖作者电脑的盘符或私人模组名称。

## 当前仍然依赖本机条件的部分

- 真实游戏运行验证需要用户安装游戏、Steam，并能访问游戏日志；本地编译成功不等于游戏中行为成功。
- Godot 场景或标准 Godot 导出路线需要用户提供兼容的 Godot 版本；当前公共包不携带 Godot 运行时。
- 图片处理脚本需要 Python 3、numpy 和 Pillow；公共包不携带 Python 运行时。
- 塔1反编译、ILSpy/CFR、第三方框架和创意工坊最终上传仍需用户提供对应工具、账号或授权。
- PCK 工具链已完成格式级互验，但不同游戏版本、不同资源类型和实际游戏挂载仍需在目标机器上验证。

## 公开化边界

私人工作区不能直接复制到这里。可以公开的是经过脱敏、抽象和复核的通用方法、失败模式、诊断路径、脚本设计和架构改进；角色名、私人路径、项目源码、未授权资源、账号信息和具体项目状态必须被删除或改成通用指代。

## 发布状态

本审计完成前不推送 GitHub。后续整合时，应把本文件、版本说明、更新日志和工作区清单一起检查，确认它们没有把“本地烟测通过”写成“所有用户环境都保证通过”。
