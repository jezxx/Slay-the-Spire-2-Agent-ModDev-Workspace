# 用户档案规则

用户档案记录一个用户的表达习惯和工作偏好，不记录与模组制作无关的私人信息。

## 可信度层级

- 明确确认：用户明确说以后都这样理解，可信度最高。
- 已观察：Agent 在多次任务中观察到，但用户尚未正式确认。
- 默认参考：工作区维护者长期使用习惯，可帮助新 Agent 起步，但不是强制规则。
- 临时推测：只适用于当前对话，不能写入正式档案。

## 判断优先级

用户当前明确说明，高于用户已确认档案；用户已确认档案，高于默认参考模板；默认参考模板，高于游戏通用术语；所有内容都高于 Agent 自行猜测。

## 可以记录的内容

- 用户如何称呼卡牌、遗物、Power、附魔和 UI。
- 用户如何区分游戏内图标、百科缩略图、百科详情大图和原始资源。
- 用户偏好的讨论、修改、验证和文档记录流程。
- 用户希望 Agent 在不确定时先问还是先做小范围验证。
- 用户对公开文案和内部技术文档的阅读习惯。

## 更新规则

用户明确确认后，Agent 可以自动更新本地档案。只观察到的习惯放入“待确认”，不能直接升级为正式规则。

用户档案属于本地层，不能进入 03-模组制作经验、根目录规则或经验传递文档。即使某个习惯对当前用户非常稳定，也不能推断其他用户应该采用同样的表达或审美。

## 与项目档案的区别

用户档案记录“这个人通常怎样说、怎样协作”；项目档案记录“这个模组具体是什么、当前做到哪里、哪些设计不能改”。两者都不能替代公共经验文档。
