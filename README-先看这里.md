# 杀戮尖塔2模组制作 Agent 工作区

这个文件夹用于帮助没有计算机和模组制作经验的人，在 Agent 协助下制作自己的《杀戮尖塔2》模组。

你不需要先理解 GitHub，也不需要先知道源码应该放在哪里。把整个文件夹放到任意位置，把文件夹路径交给 Agent，并告诉它你想做什么即可。

## 第一次使用

可以直接告诉 Agent：

    这是我的杀戮尖塔2模组制作工作区，路径是：这里填写文件夹路径
    请先读取根目录的 AGENTS.md、README-先看这里.md 和 00-开始这里/，然后再协助我完成任务。

如果还没有明确想法，可以说：

    我还不知道想做什么，请根据这个工作区已有的资料，给我几个适合新手、可以真正做出来的模组方向。

## 这个工作区包含什么

- 杀戮尖塔2 模组制作教程和来源记录
- 按游戏版本保存的反编译源码与 API 索引
- 已验证的通用模组制作经验和故障处理方法
- 图片、音频、PCK 和构建相关工具源码
- 新模组、卡牌、遗物、药水、Power、事件和资源模板
- 用户档案、项目档案、任务记录和交接规范
- 帮助 Agent 从新手描述中收集有效证据的故障问诊流程
- 一个用于不同工作区之间交换公共经验的临时经验传递文档

## 使用边界

把多个模组分别放进 09-用户项目区/ 下。每个模组都有自己的项目档案和任务记录；一个模组的实现细节不会自动变成另一个模组的规则。

用户临时提供的图片、音频和参考文件可以先放进 10-用户手动添加素材区/。Agent 必须先确认它属于哪个项目、用于哪个界面以及是否只是试听或预览素材，再决定是否复制到项目中；这里的文件不会自动进入模组或公开包。

通用经验可以在本地验证后整理到 03、04、05、06 或 08。还没有确认能推广的内容先放在待整理经验/。本地用户习惯和版本适配放在本地覆盖/或本地档案中。

根目录经验传递文档.md 只保存等待其他工作区整合的公共变化。它被交换和验证后应清理已处理事项，不是需要永久追加的总经验库。

当前发行包包含教程、0.111.0 反编译源码、API 索引、模板、工具源码和基础经验文档，仍属于内容测试版。便携运行时、完整脱敏示例和资料再分发审查仍在进行。
