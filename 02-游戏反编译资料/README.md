# 游戏反编译资料

这里按游戏版本保存反编译代码、API 索引、资源清单和版本差异。

这是工作区的原始证据层。旧版本资料不得被新版覆盖，个人解释、实验代码和项目专属结论不得直接混入反编译快照。需要补充说明时，写在对应版本说明、版本差异或 03-模组制作经验/中。

Agent 检测到游戏版本变化时，应建立新的版本目录，并记录重新反编译、差异分析和验证结果。当前运行程序集和运行日志高于这里的离线快照。

当前已加入：

    版本-0.111.0/
    ├── 反编译源码/
    ├── API索引/
    └── 版本说明.md

这份资料用于离线检索，不代表当前安装的游戏一定仍是这个版本。精确签名和资源路径在实际修改前必须重新对照用户当前环境。
