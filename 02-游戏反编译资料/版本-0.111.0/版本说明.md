# 游戏资料基线：0.111.0

## 当前内容

- `反编译源码/`：从当前工作区保存的 `tools/sts2-src` 复制的 C# 反编译源码。
- `API索引/`：从当前工作区 `Sts2ModDev/api` 导出的类型、成员、IL、PCK 和枚举索引。

## 使用规则

这是一份离线检索基线。它适合帮助 Agent 了解类名、方法名、调用链和原版实现，但不能替代当前用户电脑上实际游戏程序集的复核。

当用户环境的游戏版本与 `0.111.0` 不一致时，必须：

1. 先报告版本差异。
2. 保留这份基线。
3. 重新导出当前版本的 API 或反编译源码。
4. 对比受影响的类型、方法、资源路径和本地化行为。
5. 对新结论做编译或运行验证。

## 快照文件的边界

公开包中的 sts2.csproj 已把导出时的绝对程序集引用归一化为 Sts2DataDir，但仍不能假设它在别人的电脑上可以直接编译。Agent 应优先把源码当作离线检索材料；若确实要编译，先用当前游戏目录设置 Sts2DataDir 或重新导出工程。

API 索引中的 pck_extract 和 pck_extract2 是原始资源提取物。里面名为 json 的文件可能包含 Godot 注释、特殊编码或引擎使用的宽松语法，不一定能通过严格 JSON 解析。解析失败时先确认文件来源和编码，不要直接判断整个工作区损坏。
