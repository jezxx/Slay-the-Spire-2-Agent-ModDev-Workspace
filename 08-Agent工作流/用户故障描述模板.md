# 用户故障描述模板

不懂技术也可以按下面的顺序描述。不会回答的项目可以留空。

```text
我在哪里遇到问题：
例如：战斗中、地图、选人界面、百科、卡组界面、设置页、启动游戏时。

我做了什么操作：
请从进入页面、点击按钮、拖动卡牌或打出卡牌开始按顺序说。

我本来希望看到什么：

实际发生了什么：
例如：没有反应、卡住、闪退、红字、图标错了、声音错了、位置跳了。

这个问题能不能重复：
每次都能 / 偶尔 / 只发生过一次 / 不清楚。

涉及的对象：
卡牌、遗物、药水、状态、角色、敌人、UI、图片、音频或不清楚。

我看到的截图或错误文字：

我使用的游戏版本或模组版本：

其他可能有帮助的内容：
```

Agent 不要求用户一次填写完整。用户只说“有 bug”时，Agent 应从这里选择最关键的问题逐步询问。
