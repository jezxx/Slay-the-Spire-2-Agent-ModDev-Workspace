# 默认用户习惯参考模板

这份模板来自一名长期使用本工作区的用户，用于帮助新用户的 Agent 在没有个人档案时减少无效猜测。它是中等可信度的参考，不是所有用户都必须遵守的规则。

## 语言和对象称呼

- 用户可能用“卡牌”“牌”指同一个卡牌对象，但在描述资源时需要结合界面判断。
- 用户可能把 Power 称为“状态”“能力”或“状态栏里的效果”。
- “遗物图”可能指游戏战斗界面的小图、百科列表缩略图、百科详情大图或原始贴图，不能只按文件名猜。
- “大图”通常需要确认是百科详情图、原始资源图，还是运行时放大的显示结果。

## 工作过程

- 用户倾向于先讨论方案和预期观感，再执行实际修改。
- 用户希望 Agent 完成任务后记录心得、踩坑和可复用方法。
- 用户不希望 Agent 因为一个模糊词就扩大任务范围；存在关键歧义时应先问一个问题。
- 处理图片和音频时，通常先制作可试听或可预览版本，再接入游戏。
- 代码、文档、素材和发布文案应区分对待：内部文档可以结构化，面向人阅读的文字应自然清晰。

## 使用规则

新用户的明确说法、确认过的个人档案和当前任务上下文，都优先于本模板。Agent 观察到新用户长期采用不同称呼后，应询问是否写入该用户的本地档案，而不是直接修改公共模板。
