# 通用任务交接提示词

Agent 已经在本工作区中运行时，不需要专门提示词，直接说明任务即可。根 `AGENTS.md` 会要求它识别目标模组、任务档位、缺失参数、验证范围和 Git 边界。

如果使用的 AI 工具不会自动读取工作区规则，只需使用下面的短提示：

```text
这是我的杀戮尖塔 2 模组制作工作区：<工作区绝对路径>

请先读取根 AGENTS.md 和目标模组 PROJECT.md，按其中的任务分档、证据、验证和 Git 规则处理。缺少会改变实现的关键参数时先直接问我，不要自行补全；资料查阅在内部完成，不需要汇报检索过程。

任务：
<具体任务>
```

发生 bug 时，用户只需描述看到的现象和操作过程。Agent 应按需读取 `00-开始这里\故障问诊与证据收集.md`，一次只追问最关键的信息，不要求用户填写完整问卷。
