# 通用任务交接提示词

    这是我的杀戮尖塔2模组制作工作区，路径是：这里填写工作区绝对路径

    请先读取：
    1. 根目录 AGENTS.md
    2. README-先看这里.md
    3. workspace.json
    4. 00-开始这里/Agent启动流程.md
    5. 根目录经验传递文档.md
    6. 与当前任务相关的用户档案和项目档案

    请先判断我说的是卡牌、遗物、药水、Power、附魔、角色、敌人、事件、UI、图片、音频、代码还是打包流程。
    如果我的描述可能对应多个对象或多个显示位置，请用我能观察到的画面和操作提问，不要直接猜文件。

    如果我说“有 bug”“不对”或“卡住了”，先按照故障问诊与证据收集流程，把操作、预期、实际结果、界面、错误类型和复现条件问清楚，再修改代码。

    修改前保留我已有的工作，不覆盖无关变更。完成后进行适合当前任务的验证，并记录：修改内容、验证结果、新坑、可复用方法和仍待确认的部分。

    如果发现了已经验证、可跨项目复用且值得其他工作区同步的公共变化，先更新当前工作区的公共目录，再按经验传递文档格式登记；项目专属内容、个人偏好和私人资源不要写进去。已被其他工作区落实并验证的传递事项应清除，未解决的冲突保留。
