# 用户手动添加素材区

这里是用户把新图片、音频、视频、压缩包或参考资料交给 Agent 时使用的暂存区。

这里的文件默认只是输入材料，不代表已经批准接入任何模组，也不代表可以公开发布。Agent 使用前必须确认：

- 文件属于哪个 09-用户项目区/ 下的模组。
- 它要替换或新增什么对象，以及显示在哪个界面。
- 用户要的是原样接入、处理后预览，还是只做试听和比较。
- 文件是否有来源、授权和格式限制。
- 处理后的文件应放入项目目录的哪个资源位置。

原始文件应尽量保留，处理后的版本使用明确的临时或方案名称，避免覆盖用户原件。处理完成后，在项目任务记录中写明输入文件、处理方法、输出位置和验证结果。

这里不保存公共教程、通用经验、完整模组源码或长期构建产物。能够推广到其他项目的处理方法，先写入待整理经验/，确认后再进入公共资料；素材本身仍留在项目层。
