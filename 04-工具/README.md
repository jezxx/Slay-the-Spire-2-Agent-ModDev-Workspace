# 工具

这里放可以服务多个模组的工具源码、环境检测脚本和使用说明。

工具分为必须、推荐和可选三类。不能直接携带的外部依赖只记录来源、版本、检测方式和安装说明，不由 Agent 静默安装。

当前已加入工具源码：

- 查询工具源码/：API、成员、枚举、IL、ID、PCK 和 PNG 查询工具的项目源码。
- 通用脚本/：反编译、PCK 检查、资源扫描、脚本 BOM 修复和卡面尺寸处理脚本。

当前还没有加入预编译的便携运行时，因此这些工具需要用户电脑上具备对应的 .NET、Python 或 PowerShell 环境。

工作流目录提供从模板创建新模组，以及使用明确游戏目录编译和部署原生 C# 模组的公开脚本。脚本必须通过参数或工作区相对路径定位环境，不得带入作者私人路径、模组 ID、junction 或个人自愈逻辑。

项目专属的一次性脚本放在对应的 09-用户项目区/ 模组目录，不要直接放入这里。一个工具只有在多个项目中验证、写清依赖和失败处理后，才适合提升到公共工具区。重要的通用工具变化才写入经验传递文档.md。

公开包不会静默安装外部依赖。缺少依赖时，Agent 应先告诉用户缺什么、为什么需要、如何验证安装结果。
