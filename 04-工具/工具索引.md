## 查询工具源码

查询工具源码/ 保存可重新编译的源码，而不是把某台电脑编译出的 DLL 当作公共工具：

- ApiProbe：类型、成员、命名空间查询。
- MemberDump、SigDump：导出成员签名和精确 API。
- IlDump、IlConstScan：查看方法 IL 和常量证据。
- IdProbe、EnumProbe：核对模型 ID 和枚举。
- PckList、PckPack、PckVerify：PCK 检查和处理。
- PngGen：生成或检查 PNG。

查询结果是证据，不自动等于最终结论。Agent 仍需结合调用方、运行日志和最小验证。

## 使用原则

1. 先运行环境预检，确认当前任务所需依赖。
2. 代码修改优先用 build-native-mod.ps1 或 dev.ps1，不要从固定 bin 路径猜产物。
3. 资源、本地化、图片、音频和场景变化必须重新导出 PCK。
4. 反编译和 API 导出按版本保存，不覆盖旧版本资料。
5. 工具输出必须记录输入版本和输出路径。
