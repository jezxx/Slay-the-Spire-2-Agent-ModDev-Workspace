# 待整理经验

这里保存 Agent 在用户项目中发现、但尚未确认可以推广到其他模组的经验。它是本地孵化区，不是公共经验库，也不是跨工作区交换文件。

每条经验应包含：

- 用户遇到的现象和最小复现操作。
- 当前判断的真实根因，以及仍不确定的部分。
- 适用版本、修复方法和失败方案。
- 源码、日志、最小示例、构建或运行验证证据。
- 是否只适用于某个模组，是否依赖私人资源或路径。
- 后续应该留在项目目录、提升到公共目录，还是暂不传播。

只有确认具有普遍价值、已经脱敏并且值得其他项目同步的内容，才整理进 03-模组制作经验、04-工具、05-模板、06-示例项目或 08-Agent工作流。需要其他工作区落实的公共变化，再摘要写入根目录经验传递文档.md。
