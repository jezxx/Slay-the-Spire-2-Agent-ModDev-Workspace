# 官方与社区教程

这里放经过来源记录的原始教程和项目整理后的教程索引。

原始教程保留来源、版本和提交信息；整理后的教程必须标明哪些内容来自原文，哪些内容是本工作区根据实测和当前游戏版本补充的。

这个目录是教程证据层，不是某个项目的经验区。Agent 可以在专题文档中引用这里的内容，但不能把个人项目的做法直接改写进原始教程。发现教程与当前版本不符时，在 03-模组制作经验/或版本差异文档中记录核对结果。
